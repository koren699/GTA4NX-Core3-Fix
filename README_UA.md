# GTA4NX Core 3 Fix — Nintendo Switch

**Перевірене спільнотою виправлення звуку та плавності роботи** для [порту GTA IV на Switch](https://github.com/kabba536/Grand-Theft-Auto-IV-Native-Port-Nintendo-Switch). **[English README](README.md)**

> Це незалежний патч, а не офіційне оновлення автора порту. Працює з форвардером GTA4NX у HOME-меню, Title ID `03DB149512496000`. Гри, NRO й файлів перекладу в репозиторії немає.

## Завантаження і встановлення

**[Завантажити готовий ZIP для Atmosphère](GTA4NX_Core3_Atmosphere_Fix.zip)** (на GitHub обери Download raw file).

1. Повністю закрий GTA IV. Зроби резервну копію `atmosphere/contents/03DB149512496000/`, якщо така папка є.
2. Розпакуй ZIP **у корінь microSD**. Шлях файлу: `sdmc:/atmosphere/contents/03DB149512496000/exefs/main.npdm`.
3. Перезавантаж Atmosphère і запускай той самий форвардер GTA IV із HOME-меню. Для інших Title ID файл не призначений.
4. Перевір стабільність звуку та FPS під час руху містом.

**Як відкотити:** видали лише `sdmc:/atmosphere/contents/03DB149512496000/exefs/main.npdm` і перезавантаж систему. Якщо твій спосіб запуску не застосовує ExeFS override, патч може не діяти.

## Що змінюється

У двох таблицях прав NPDM (`ACI0` та `ACID`) змінено тільки `MaxCoreNumber` з **2 на 3**. Завдяки цьому аудіопотік XAudio2 у самому порту отримує змогу використовувати четверте процесорне ядро. Патч **не розганяє консоль** і не змінює NRO.

- SHA-256 перевіреного `main.npdm`: `79e356394589662cae4a8b8cf593d3a0c6f73467ab8c91d2dca74e0b8c2d8ca0`
- Під час тесту зникло заїкання звуку, а гра стала відчутно плавнішою. **Постійні 30 FPS поки не підтверджені.**

## Розгін для поточного тестування

| Компонент | Частота |
| --- | ---: |
| CPU | **1963 МГц** (попередній скріншот sys-clk-OC) |
| GPU | **921 МГц** (поточне налаштування тестувальника) |
| RAM | **2131 МГц** (попередній скріншот sys-clk-OC) |

**Зараз тестувальник встановив GPU 921 МГц.** На попередньому скріншоті було **768 МГц**, оскільки OLED обмежував розгін налаштуванням температурного ліміту; згодом це обмеження було виправлено. Значення CPU 1963 МГц і RAM 2131 МГц узяті з попереднього скріншота, тож таблиця не є заміром усіх трьох частот в одному новому тесті. Це **орієнтир, а не обов'язкова вимога**, і він не гарантує стабільні 30 FPS. Вищі частоти можна використовувати лише за підтримки конкретної консолі, достатнього охолодження й перевіреної стабільності. Не вимикай термозахист; іншим консолям можуть знадобитися нижчі частоти.

## Виправлення російських шрифтів

Якщо ти окремо встановив **Russian Text Mod**, збережи в `sdmc:/switch/gta4nx/LibertyRecomp/native.toml`:

```toml
gta4_native_vector_fonts = false
```

Без нього після заміни `native.toml` замість тексту можуть з'являтися ієрогліфи. У грі переклад зазвичай вибирають через **Italian**. Русифікатор у цьому репозиторії не поширюємо.
